# 首板模式工作台

基于 `docs/策略/首板模式/` 的八份课程文档，将选股、盯盘、证据记录、模拟交易和规则比较放在独立的「首板模式」菜单中，地址 `/first-board`。底层复用现有行情仓库、策略库、通知和模拟盘。

课程中的盘感、题材主线、扫板与排板不能仅由日线准确还原。因此本功能把课程思想与可检验的实验参数分开呈现，不把观察统计包装成可成交胜率。

## 使用流程

1. 在数据配置中准备股票日线、上证指数日线、实时行情，以及市场环境历史和行业扩展数据。实时能力必须可用，并开启系统的全局实时行情。
2. 打开「首板模式 → 规则版本」，确认参数并保存。默认关闭盯盘；启用后由后台工作线程持续消费行情，离开页面仍可运行，应用须保持运行。
3. 「今日盯盘」按上一完成交易日构建候选，再用当前行情展示观察、临近涨停、涨停价观察、打开涨停或数据无效状态。查看个股的形态证据、环境、行业联动及禁止买入的原因。
4. 满足规则时生成买入候选提示，复用系统通知、页面通知和提示音/语音的现有开关。「信号记录」可按日期查看规则版本和触发证据。提示不会自动向券商下单，也不会自动创建模拟委托。
5. 如需跟踪成交表现，先在现有模拟盘创建账户，再关联该账户。点击模拟买入/卖出由既有撮合与账务处理。建议使用专门账户，以便统计清楚。账户统计包含该账户的所有交易，不只首板来源。
6. 「效果验证」选择已完成的历史日期，运行日线观察统计或规则比较。查看样本覆盖和缺失情况，再决定是否修改规则。研究记录、数据指纹和规则版本均保存，比较结果不会自动替换盯盘参数。

## 课程思想如何落地

| 内容 | 当前实现 | 能力边界 |
| --- | --- | --- |
| 首板身份 | 最近 N 个实际交易日没有收盘涨停 | 用户确认默认 N=10；不是固定自然日，也不是只排除昨日涨停 |
| 个股形态 | 平台突破、趋势加速、超跌反弹三类观察池 | 定量条件为工程实验假设，不是课程原文给出的精确阈值 |
| 市场环境 | 使用候选参考完成日的现有环境状态 | 缺失、重复、错日或状态未知时禁止买入提示 |
| 板块联动 | 当前行业二级归属的横截面联动 | 至少 3 只有效行情、2 只涨幅 ≥5%、平均涨幅 ≥1%；不等价于精确题材主线 |
| 盘中观察 | 当前价格、原价日内高点、涨幅、成交额、换手率与突破条件 | 快照不是逐笔订单流；日内高点不能证明回封先后 |
| 打板、扫板、排板 | 展示接近涨停、涨停价与打开状态 | 不模拟封板队列；涨停价观察不产生可买断言 |
| 分仓与退出 | 个股、行业、总仓位、持仓数，T+1 可卖量与次日退出提示 | 默认次日 10:30 或成本下跌 3% 后提示，仍需人工执行；阈值可改 |
| 复盘与改进 | 日线观察研究、时间留出比较、版本记录、模拟盘统计 | 分钟精确成交及队列成交验证当前不可用 |

## 默认规则

仅覆盖沪深主板非风险警示股票，至少需要 60 个历史交易日；历史窗口有缺口、价格无效或 OHLC 矛盾时排除候选。

| 参数 | 默认值 |
| --- | --- |
| 首板排除窗口 | 10 个实际交易日 |
| 平台观察 | 20 日最高/最低振幅不超过 18%，昨收距平台高点不超过 8% |
| 趋势观察 | 20 日涨幅 3%–40%，昨收在该窗口均价之上 |
| 超跌观察 | 相对 60 日高点回撤至少 25% |
| 临近涨停提示 | 突破历史参考高点、涨幅至少 5%、距涨停价不超过 3% |
| 流动性 | 换手率 2%–30%，成交额至少 5000 万元 |
| 行情时效 | 同一北京时间交易日，行情时间距当前不超过 30 秒 |
| 环境 | 强势、偏强、震荡；默认要求行业联动确认 |
| 仓位 | 最多 4 只，单股 25%，同行业 50%，总仓位 50% |

平台采用平台高点作为突破参考，趋势和超跌采用此前 5 日高点。涨停价、委托、仓位估值使用原价；形态和收益观察使用复权价。除权日将前收盘转换到当日原价尺度。涨跌幅为小数（0.05=5%），enriched 换手率为百分数值（2=2%），成交额为元。

连续竞价观察窗口为北京时间 09:30–11:30、13:00–14:57，边界结束时刻不包括在内。非交易时段、未知/过期时间戳、重复行情、缺少当日高点、环境未通过等情况不会给出买入提示。行情来源与可用性沿用现有能力矩阵，不新增数据供应商直连。

## 统计口径

日线研究每个 T 日仅使用 T-1 及更早完成日线生成候选，然后观察 T 日是否触及涨停、是否收盘涨停，以及 T 收盘至下一交易日开盘/收盘的复权变化。这些收益不扣成本，不假设买入成交，**不是交易胜率**。三类形态可能重叠，同股同日的多形态分别计样本，另列股票日数量。

单次研究最多 366 个自然日。缺少下一交易日数据时保留缺失，不跳过缺日改取再下一天；缺价格不按零收益填充。返回缺口、样本数、分母、数据指纹及历史名称来源。历史风险警示名称、退市样本与行业历史归属仍受本地数据覆盖限制。

规则比较以时间前 70% 为训练、后 30% 为固定留出验证，比较当前基线与三个小幅参数变体。只用训练封板观察率选择变体，清除跨分割边界的次日收益标签；至少需要 30 个训练和 10 个验证有效样本。缺少日历参考、存在观察缺口或留出区间不优于基线时不推荐修改。重复查看同一留出段也可能造成过拟合，仍应继续积累新的前向记录。

关联模拟账户的已完成交易统计来自现有账本，包括费用、滑点、涨跌停约束与 T+1；没有完整交易时胜率显示为空。工作台拒绝开启「涨跌停排队」选项的账户发起委托，避免将现有延后重试功能误解为真实排队成交。

## 接入与存储

- **L1**：三张内置日线观察策略复用 `app.strategy.first_board`，进入现有策略库。
- **L2**：`app/custom/first_board.py` 注册 API，`frontend/src/custom/first-board/extension.tsx` 注册页面及菜单；不复制核心策略页。
- **L3**：`main.py` 管理服务生命周期，`quote_service.py` 提交已有 enriched 快照并复用通知出口，策略加载白名单允许共享规则模块，通知界面增加中文来源与工作台跳转。

行情线程仅提交最新快照；历史加载、环境校验、风险计算和留痕由独立线程处理。未启用时不复制行情或扫描历史。候选预热按交易日期和规则版本缓存，最长 5 分钟刷新，强制刷新及规则保存会失效。页面轮询复用集中查询键，保存后刷新规则、版本、快照和事件；规则保存检查版本冲突。

运行数据写入 `data/user_data/first_board/`：

- `config.json`：当前配置和不可变历史版本。
- `events/YYYY-MM-DD.json`：当天状态、去重信息和事件证据；重启延续去重。
- `research/*.json`：研究/比较结果和指纹。

配置和事件采用原子写入；损坏文件保留并关闭相关提示/委托，不自动覆盖。研究同时仅运行一个任务。模拟账户仍保存在现有模拟盘目录，无第二套资金账本。

API 前缀 `/api/first-board`：`GET/PUT /config`、`GET /versions`、`GET /snapshot`、`POST /refresh`、`GET /events?day=YYYY-MM-DD`、`POST /research`、`POST /compare`、`GET /research-runs`、`POST /paper-order`。模拟委托请求必须引用当前有效事件，下单时再次核对规则版本、交易时段、行情、账户预算与可卖数量。
