# 首板模式工作台

`/first-board` 提供「今日盯盘、信号记录、效果验证、规则版本」四个标签页，复用现有行情仓库、市场环境、行业数据、监控通知和模拟盘。

## 使用流程

1. 准备股票及上证指数日线、市场环境历史和行业数据。盘中盯盘还需要可用的实时行情能力，并开启全局实时行情。
2. 在「规则版本」确认市场范围、三类形态和风险参数，保存后生效。默认不开启自动盯盘；开启后应用须保持运行。
3. 在「今日盯盘」查看候选及形态证据。历史形态观察池由上一完成交易日建立，盘中列表按「盘中最低涨幅」筛选，当前涨幅低于门槛的股票退出列表，达到门槛后重新进入；恰好等于门槛时保留。缺少必要数据、无法计算涨幅时保留无效原因并停止买入提示。
4. 在「信号记录」按日期查看触发证据，可组合筛选形态和状态；状态与记录标签一致，包含买入候选、临近涨停、退出提示等。切换日期或标签页保留筛选，选择「全部形态／全部状态」取消对应条件。监控中心支持「首板模式」规则，可选择事件、标的范围、冷却时间和通知渠道。
5. 如需模拟交易，先创建并关联现有模拟账户，再人工提交模拟买入或卖出。不会自动提交模拟委托或向券商下单。建议使用专用账户；账户统计包含其全部交易。
6. 在「效果验证」运行日线观察研究、规则比较，或切换「交易链验证」检查已记录信号的分钟成交回放和模拟盘归因。比较结果不会自动替换当前规则。

## 候选列表与特别关注

### 盘中数据状态摘要

在「今日盯盘」查看本次快照有多少只候选获得了新鲜报价、剔除本股后的行业或概念排名、原价分钟、人气榜、题材旁证、前一交易日均线与 MACD，以及首板优先分。分母取本次快照可见的全部候选股票，每只计一次；切换形态、改变排序或勾选「只看可提示候选」只影响下方列表。已核验的弱板块也算有排名，完整人气榜的榜外股票算有人气数据。题材旁证只计当时明确匹配的股票。

展开「覆盖口径与缺失原因」可查快照日期、报价有效期、全局实时行情、分钟数据与最近五分钟采样。盘中缺分钟时可检查监控设置中的全量分钟落盘。收盘后复核时，应区分当日留下的技术依据与需要实时行情才能判断的分项。

### 首次提示排名对照

在「信号记录」选交易日后，可切换当天出现过的规则版本，查看「首次提示排名对照」。默认取有买入候选的最新版本。**同批名次**表示同一毫秒首次发出提示、且该方案证据可用的股票之间的顺序。**当日席位**先按提示时间占位，同批再按方案排序。同股同一时刻的多个形态合并，日内再次提示沿用首次记录。

涨幅、不含人气的基础分、含人气的优先分分别展示。技术组仅纳入原优先分、均线与 MACD 三项齐全的股票，按与「效果验证」相同的口径比较原分、加入均线、加入 MACD 及两项合用。阅读时先看各方案的覆盖数，再比较同一只股票的名次。选择「各组前 3／前 5」会显示任一方案获得相应席位的股票并集，因此可能看到超过 3 或 5 只。可展开「首次依据」核对当时涨幅、分数、形态与人气。缺少归档分项的位置显示为「—」。

摘要复用首板快照的可选 `data_status`。排名接口 `GET /api/first-board/first-alert-rankings` 接受 `day`、可选 `revision`、`top_n`（3 或 5）及 `offset/limit`（每页默认 100、最多 500）。服务按整日排名后筛选和分页，`total` 为所选版本的全日首次提示股票数，`matched` 为筛选后数量。榜单只读已保存的首板事件，缓存随日期、版本、事件档案或日历更新。该 L3 局部扩展基于 `97d7f5bc`，升级时复核快照状态、首事件归并与回放排序口径。

### 候选显示与筛选

盯盘卡片表头显示盯盘状态、市场环境、环境是否允许提示、候选形态数和股票数，以及交易日期、快照时间和规则版本。卡片默认展开，收起后表头继续刷新，再次展开会保留右侧反馈的市场范围和明细展开状态。

快照在「今日盯盘」和开启盯盘时查看当日「信号记录」期间每 5 秒刷新，其他情况每 30 秒刷新页头状态。

「今日候选」表格视口固定为 560px，矮屏最高为视窗高度的 70%；数据和展开的依据在表格内部滚动，列头保持冻结，窄屏可在内部横向滚动。加载和空列表也保留相同视口高度。

候选可按形态、状态、重点关注及「只看可提示候选」组合筛选。状态沿用列表标签：观察中、临近涨停、涨停价观察、已开板、已失效；选择「全部状态」取消状态条件。筛选结果同步影响条数和个股详情导航，保留当前排序；切换标签页和刷新报价保留筛选，状态随新快照重新匹配。此 L3 局部改动基于 `bf2abc922ad4cb90a28853044ede0412b7fbb917`，复用原快照，不新增 API 或修改行情缓存；升级时复核候选筛选与状态标签。

点击个股下方的「特别关注」后，该股在当前筛选结果中优先显示；同股不同形态共用关注状态。关注与未关注两组内部继续按当前列头排序，点击「取消关注」后恢复原排序位置。个股详情的上下切换沿用显示顺序。关注按股票代码在当前浏览器保存，刷新、切换标签页及新报价不会清除；保存失败会提示重试。

该局部界面改动按 L3 管理，基于 `c0fadf624ec5f557f8361f418b1698394c45a486`；现有首板表格没有可表达滚动布局和排序状态的插槽，因此直接调整原组件。标记存取和稳定分组复用回春模块提取的共享 hook，各模式使用独立存储键。没有新增 API 或行情查询，候选快照缓存和筛选仍使用原调用链。合并上游时应复核候选表格、列排序、详情导航和共享标记行为。

## 规则与数据口径

默认范围为沪深主板、创业板及科创板的非风险警示股票，不含北交所、B 股、ETF 和指数；也可选择仅沪深主板。三类形态为平台突破、趋势加速、超跌反弹。定量阈值是可验证的实验参数。

| 参数 | 默认值 |
| --- | --- |
| 首板排除窗口 | 最近 10 个实际交易日没有收盘涨停 |
| 最少历史 | 60 个交易日 |
| 盘中候选范围 | 当前涨幅至少 5%，列表数量同步按筛选结果统计 |
| 临近涨停确认 | 突破形态参考高点、涨幅至少 5%、距涨停价最多 3%；20% 涨跌幅股票单独设置，默认同为 3% |
| 流动性 | 换手率 2%–30%，成交额至少 5000 万元 |
| 行情时效 | 同一北京时间交易日，最长 30 秒 |
| 市场环境 | 强势、偏强、震荡 |
| 行业联动 | 默认要求完整行业成员报价覆盖 ≥80%、至少 3 只有效成员、2 只涨幅达 5%、平均涨幅至少 1% |
| 仓位上限 | 最多 4 只；单股 25%、同行业 50%、总仓位 50% |
| 次日退出提示 | 10:30 或成本下跌 3%，仍需人工确认；盈利退出与涨停暂缓默认关闭 |
| 昨日首板反馈门控 | 默认关闭 |

形态和收益观察使用复权价；涨停判断、估值及委托使用原价。涨跌幅是小数（`0.05=5%`），enriched 换手率是百分数值（`2=2%`），成交额单位为元。

新版流水线的 `limit_up_price` 是交易所生效价减 `0.005` 后的判定阈值。盘中直接消费该列，还原展示价格时只补回一次容差。缺列、空值、非有限值及无价格限制日不猜测涨停价；不依赖已移除的 `limit_up` 信号列。历史研究仅在输入完全没有判定价列时使用旧窄表兼容计算，显式空值仍保持无效；创业板历史按改革日期区分规则。

观察窗口是北京时间 09:30–11:30、13:00–14:57（不含结束时刻）。过期、未来或重复行情、缺失原价高点、历史缺口、无效环境均阻止买入提示。行业横截面联动不能代表完整题材主线，快照高点不能证明回封先后，涨停价观察不代表可成交。

模拟委托复用原有撮合、手续费、滑点和 T+1 规则；提交时再次检查事件、版本、行情、预算和可卖量。开启涨跌停排队的账户被工作台拒绝。科创板买入至少 200 股，沿用现有百股步长；689 存托凭证可观察和研究，但暂不通过工作台提交模拟委托。

退出数量只包含能够明确归属首板、位于账户先进先出队首的连续可卖批次，并扣除待成交卖单占用。同股同日混合买入来源时，现有账本无法区分剩余批次归属，因此不生成该日期的退出提示，也不跳过较早手工批次去卖出较晚首板批次。

止损成本从成交台账按 FIFO 重建，计入实际买入费用、已卖出数量和公司行动，再扣除待卖订单占用的队首批次；不使用同股手工加仓后的账户整体均价。重建结果须与现有持仓批次核对一致，成本或来源无法确认时停止该标的退出提示，不改写原账本。

临近涨停距离按该股当日的涨跌幅制度取阈值：适用 20% 涨跌幅的创业板、科创板股票使用「20% 涨跌幅股票距涨停价最多」，其余使用 10% 档阈值。

以下三项可在「规则版本」开启，默认保持原行为：

- 盈利退出：现价达到同一批次成本的设定涨幅时提示退出，成本口径与止损相同；留空表示不启用。
- 涨停时暂缓：现价不低于涨停判定价时，暂缓定时退出和盈利退出。止损不受影响；缺少判定价时按原规则提示。
- 昨日首板反馈门控：昨日首板今日的整体平均涨幅和上涨占比须达到下限（默认 0% 与 50%），否则暂停买入提示和影子观察。反馈须为当日盘中实测，样本至少 10 只、行情覆盖至少 80%；证据不足同样暂停。判定结果记入候选证据 `feedback_gate`。

成交回放读取样本中冻结的配置执行上述退出规则；旧样本没有这些字段，按未启用处理。

行业确认的覆盖率分母为当前完整行业映射，缺失、重复、无效或过期报价不缩小分母。裸代码通过股票维表唯一映射后与完整代码去重；无法唯一解析成员的行业不参与确认。返回的 `sector_confirmation.member_count/count/coverage` 分别表示完整成员数、有效报价数和小数制覆盖率，原因文案同时展示覆盖情况。行业二级代理仍不代表真实题材主线。

## 昨日非一字涨停股的今日开盘表现

「今日盯盘」左侧统计上一交易日收盘涨停、当日最高价与最低价不同的沪深非 ST 股票，首板和连板均计入。样本来自已完成的日线，涨停依据和原价价格区间均须可核验。

横条按今日开盘相对有效昨收参考价的涨幅统计只数。正负方向均以 2 个百分点分档，按绝对值包含上界；平开、超过 +10% 和低于 −10% 各自单列。「打板成功率」为高开数除以有效开盘数，「打板盈利率」为有效样本开盘涨幅的等权平均值。两项指标均描述价格表现。缺失开盘数据的股票保留在样本总数中，有效开盘数为零时两项指标均为空。

该统计随首板快照中的可选字段 `yesterday_feedback.opening_distribution` 下发，与右侧首板反馈共用历史分区读取和行情刷新。右侧市场范围与下方候选筛选只作用于各自区域。

## 昨日首板反馈

「今日盯盘」顶部提供昨日首板整体表现，支持全部、沪深主板、创业板／科创板切换，并可展开个股、行业和概念对照。它是市场反馈，不改变市场环境判定、买入提示或模拟委托权限。

样本按上一实际交易日的收盘首板建立：当日原价达到有效涨停判定价，前一交易日有有效日线且未收盘涨停。范围固定为沪深非 ST 股票；无涨跌幅限制、交易日证据不足和历史缺口不能猜测为首板。缺少首板识别依据的股票数量另列提示，不把这些股票全部称为昨日涨停。它不使用当前策略的近 N 日无涨停、形态或盘中最低涨幅条件，今日下跌、缺报价的已确认样本仍保留在名单和覆盖分母中。

| 指标 | 口径 |
| --- | --- |
| 平均溢价、中位数 | 有效样本当日涨跌幅的等权均值、中位数，小数制；不是实际买入收益 |
| 上涨占比 | 上涨样本数／有效报价样本数，另列固定样本总数与覆盖 |
| 当前二板 | 昨日首板中当前原价达到当日有效涨停判定价的数量；缺判断依据时保留未知，不宣称最终晋级 |
| 跌超 5% | 当日涨幅 ≤−5% 的数量与比例，包含恰好 −5% 的边界 |
| 开盘溢价 | 今日开盘相对同口径昨收基准的收益均值 |
| 开盘后涨幅 | 今日当前价相对今日开盘价的收益均值；不是两个平均溢价直接相减 |

报价重复、日期不符、非有限值、无效价格和盘中过期数据不作为有效样本；缺失不填零。盘中沿用行情时效设置，默认检查 30 秒新鲜度；同一表现日期刷新失败或过期时保留最近结果并提示状态，跨日失败不复用旧池。盘后展示最近行情快照及日期，不把普通快照标为已确认收盘。小样本提示与报价覆盖一起展示。

行业／概念表固定使用沪深非 ST 全范围，与上方主板／双创切换分开标注。表中同时显示关联昨日首板的表现和整个板块成分股的等权涨幅、上涨比例、行情覆盖；二者不能互相替代。完整成员不少于 5 只、关联昨日首板不少于 2 只且行情覆盖至少 80% 时才作为可用对照，数据不足保留原因。成分来自当前已接入目录，不代表历史时点归属或个股涨停原因；多概念重叠，不能跨概念加总。

反馈通过原有首板快照接口的新增可选字段 `yesterday_feedback` 下发，前端共用原有查询与刷新，不增加每卡片请求。历史名单、成分准备和计算在后台完成，行情回调仅投递快照。历史只读三个明确的股票日分区，复用共享限价计算；分区及股票资料签名变化时重建名单，当前交易日行情落盘不使昨日历史缓存失效。必要时使用短区间指数日线确认近期新股的交易日序号。

本次为基于 `6d38f22a1d6d59b832c72b9a80f973a9838fb74d` 的 L3 局部扩展，沿用现有工作台注册入口，不增加虚构的候选过滤扩展接口。新反馈不依赖分钟、逐笔或封单数据，暂不提供精确首封时间、炸板次数和同步分时整体曲线，也不迁移或改写已有用户数据。后续升级重点复核仓库窄读接口、首板服务快照接线及前端新增字段；旧配置和事件格式不变。

## 研究边界

### 板块联动重点观察（首期）

「今日盯盘」新增板块联动列，可筛选强势板块、领涨带动、同板块双条件，或按关注优先级升序／降序排列；第三次点击恢复默认顺序。未知结果始终置底。展开「联动依据」查看来源、排名、覆盖、首次观测触板时间及分钟证据。标签不改变形态状态、原有行业确认、买入门槛或模拟权限。低于最低涨幅的股票不显示在盘中候选列表，但后台仍跟踪完整历史形态观察池，保留条件失效、炸板等状态记录与研究样本。

`attention-v1` 的固定实验口径如下；这些门槛尚未证明能提高次日溢价。

| 证据 | 首期定义 |
| --- | --- |
| 强势板块 S | 同来源、同分类字段内排名前 20%（同值并列）；至少 5 只有效成员且报价覆盖 ≥80%；平均涨幅 >0 且高于该来源分类覆盖股票的去重平均；上涨家数占比 ≥60% |
| 领涨触板 | 同一行业或概念中，除候选自身外，系统已观测到触及涨停判定价、且本次新鲜报价仍在涨停价的成员；优先最早被观测者 |
| 分时走强 | 使用已完成的 6 个一分钟收盘端点计算近 5 分钟收益；收益和价格斜率为正，末价高于当日累计量额均价，窗口收盘价最大回撤 ≤1% |
| 领涨带动 F | 候选当前未触板；整个 5 分钟窗口严格晚于领涨股首次被系统观测触板，并同时满足分时走强 |
| 同板块双条件 | 至少一个相同板块同时满足 S 和 F；两个不同概念分别命中不合并为双条件 |

板块均值不是全市场指数收益。成员继承现有行业／概念目录，保留来源和分类字段身份，优先行业二级，过滤属性概念及超过 300 个成员的过宽分组；按首板市场范围排除风险警示股票。裸代码只通过股票维表映射；含无法唯一映射成员的分组整体排除并说明。成员分母不随行情缺失缩小。

显式声明 `market_level` 的扩展数据是市场报告或事件表，即使包含概念字段也不作为股票成分来源；其更新不触发成分缓存失效。真正成分源的缺键或读取失败仍会停止联动计算，避免用不完整目录进行排名。

“首次观测触板”不是交易所首封时间，也不证明封单稳定；开板后撤销当前领涨带动，重启后重新积累先后证据。强势、联动、分时采用 `true/false/null`，数据不足不当作未满足。行情过期、暂停盯盘、非连续竞价或快照失败后清除当前正向标记，仍可查看最近观测证据。

分钟输入只批量读取当日本地分区，须有已确认原价基准和可用分钟能力；量为手、额为元。新写入的 TickFlow 当日全量修复轮／增量轮附带逐行 `minute_price_basis=raw` 和 `minute_time_grid=auction_end` 证据；读取及分区合并保留这些字段。原价证据必须覆盖该股票截至计算时点的全部已完成分钟，新增尾部记录不能替旧记录证明口径。缺少逐行证据的旧分区仍须通过已有原价迁移标记确认，且读取未发生复权投影；显式未知或非原价声明不由迁移标记覆盖。不会据当前数据源设置推断存量来源，也不会自动迁移历史或创建标记。

合并时，只有原本完全没有价格基准字段的旧分区，才可凭既有迁移标记保留原价证据；旧字段中的空值不补，新输入未声明口径时也不继承被覆盖记录的证据。

均价要求从当日开盘开始完整，午后不能只取下午数据。未声明时间网格时保留 09:30／13:00 或 09:31／13:01 两种一致的 240 根序列；显式 `auction_end` 支持独立的 09:30 开盘点加 09:31–11:30、13:01–15:00 的 241 点序列，开盘量额计入当日均价。网格声明不代表精确交易所完结时刻，仍仅使用时间戳严格早于当前分钟的数据；不挪动标签、不补缺根。缺基准、混合口径、量额不符、重复、迟到或缺根时显示原因；首板读取本身不触发远程补数。

### 首板优先分与题材人气

“今日盯盘”在连续竞价且有新鲜个股行情时展示 `priority-v2` 实验优先分。可按“强概念／题材成员”或“强行业成员”筛选，再选具体板块和来源。同一股票可在多个真实归属下被找到。按优先分排序时可提示候选优先，已特别关注的分组保持置顶。展开分数可查看分项、可核验分值上限、板块来源与名次，以及人气的供应商更新时间和本机收到时间。分数用于同状态排序，预测胜率仍待前向验证。

| 分项 | 上限 | 输入 |
| --- | --- | --- |
| 个股强度 | 40 | 距本股涨停价的距离（15 分）、量比（15 分）、首次临板时段（10 分）。原价突破、成交额与换手已是临板门槛，只做有效性校验 |
| 板块强度 | 30 | 剔除本股后按来源与分类排名（12 分）、与同范围股票的超额涨幅（10 分）、同行上涨广度（6 分）、相隔 3–10 分钟的持续强势观测（2 分）。只取证据最强的一组，雷达旁证最多补 2 分，仍受本项已知上限约束 |
| 时机与角色 | 20 | 先锋看板内相对位置和已完成分钟的走强，跟随股看同板块先行触板与随后的分时表现 |
| 个股人气 | 10 | 当时已收到的同花顺前百名次最高 8 分；同日两次可比较的盘中观测提供最多 2 分的升位依据 |

个股强度的三个分项：

- 距离：按当日适用阈值计 `15 × (1 − 距离 ÷ (2 × 阈值))`。
- 量比：当日每分钟均量除以前 5 个完整交易日的每分钟均量（日成交量 ÷ 240），1 以下不得分，3 及以上满分。开盘不足 5 分钟、或前 5 日任一日成交量缺失时为待确认。
- 首次临板时段：取同日同规则版本首次进入临近涨停的时刻，重启后从当日事件恢复；尚未临板的观察股按当前时刻计。10:00 前满分，14:30 后不得分。

连续竞价分钟数扣除午休。待确认的分项不计入可核验上限。

来源未知时保留分项缺失，分值只累计已核验的证据。个股可以先进入“待临板”观察。仅在原有各项买入条件全部通过时显示可提示。行业行情覆盖充分但强度未通过、同时有强概念证据的临板候选，在环境和预算也通过时单列为影子观察，不下模拟委托。已封板、开板、失效或过期时撤销当前分；同日同版会话可显示最近一次盘中评分，历史信号保留触发时的证据。

盘中有可见候选时，后台至多每五分钟更新人气与可用雷达。供应商三类板块各取当期上涨的榜首，按类别、代码及日期核实成员。官网精选只给其实际出现的核心股票提供旁证。仅使用源时点和接收时点均能核验的当日盘中数据，时效窗口十分钟。完整前百榜可区分未上榜与缺数据，成功的人气观测按日期保留。分钟项依赖当天本地分钟分区与可证明的原价，需要盘中积累时在「设置 → 监控」检查全量分钟落盘及数据源能力。

“效果验证 → 交易链验证”运行已记录信号成交回放后可查看“首板优先分对照”。三组使用同股同日首次可提示时已经有评分的共同样本，每日按到达顺序占用 3 或 5 个名额，同一批分别按原涨幅、基础分、包含人气的分数排序。完整区间和后段验证期按有评分交易日的先后划分，至少两天才显示后段。可按主板／双创、先锋／跟随和人气覆盖查看入选后的子组。收盘未能核验的股票保留在信号数中，已成交但尚未闭环的样本不计入闭环净收益。影子组单独回放。升级前的归档继续参加原规则验证，不用今天的热榜或成员补评分。

`priority-v1` 归档继续显示和参与回放。升级当日若同时存在两个版本，名次只在较新版本内比较，旧版本样本计为未评分；报告的 `version`／`baseline` 为实际比较的版本。

### 前一交易日的均线与 MACD

在「今日盯盘」候选的入选依据、以及「信号记录」的历史依据中，可展开「前日技术」查看参考交易日、指标值和各自的判断理由。两项判断专用于排序实验，实盘沿用原优先分与买入条件。指标只用信号日前已经结束的交易日。日线按参考日原价统一复权，均线采用简单移动平均，MACD 沿用系统 12、26、9 参数，柱值等于两倍 DIF 与 DEA 之差。

| 候选形态 | 均线符合条件 | MACD 符合条件 |
| --- | --- | --- |
| 平台突破 | 参考日收盘 ≥ MA20，且 MA20 ≥ 前一日 MA20 | DIF > DEA |
| 趋势加速 | 参考日收盘 ≥ MA5 > MA10 > MA20 | DIF > 0，且柱值 > 0 |
| 超跌反弹 | 前一日收盘 < 当日 MA5，参考日收盘重新达到或超过参考日 MA5 | 前一日柱值 < 参考日柱值 < 0 |

均线要求最近 21 个交易日都有有效收盘，MACD 采用连续 120 个交易日预热。日历或参考日无法核对、重复日线、无效价格、明确带有盘中或错日时间戳的报价，均会让相关指标显示未知。无报价时间戳的旧日线沿用历史日 K 口径。两项的覆盖分别判断。交易日、候选与历史日分区签名用于复用计算。每次触发和每个五分钟样本分别保存当时的 `evidence.technical_shadow`，版本为 `ma-macd-shadow-v1`。旧事件保留原始证据。

在「效果验证 → 交易链验证」运行已记录信号回放，可查看「均线与 MACD 影子排序」。这项对照使用选定规则版本下每只股票当日首个实际买入候选事件，包括五分钟采样之间的提示。同一股票同一时刻符合多种形态时，以当时原优先分最高的形态为代表，同分按形态代码排序。首条记录缺少原分或指标时，覆盖统计仍保留这个股票日，后续提示不能替它补齐资料。

四种排序在三项证据齐全的同一批股票日内比较，分别使用原优先分、均线、MACD、均线与 MACD。每日取先到的 3 或 5 只股票，仅同一批次、同一形态且与该档最高原分相差最多 2 分的候选能调整顺序。均线和 MACD 各计一票，票数相同保留原序，后来的信号无法占用早先名额。先看名额边界有竞争的天数、实际换入只数，再对照封板数、可核验收盘数、模拟入场数及次日闭环扣费收益。三个形态共用每日名额，可查看入选后各形态的结果。可比交易日达到两天后，按日期先后划出后段验证期。交易机会、可核验收盘与次日已退出交易使用各自的分母。

该改动按 L3 管理，基于 `97d7f5bc`。升级时复核首板候选准备、日线分区读取、事件证据归档、成交回放和保存报告的契约。新字段均为可选，复用现有首板接口和页面查询。

### 前向样本积累

启用有效盘中盯盘后，在每个 5 分钟锚点所在分钟采集一次完整历史形态观察池，包含低于盘中最低涨幅的负例及未知，不受盘中列表筛选影响。采样按股票去重，同时保留全部形态与当时交易权限。样本及其覆盖计数均按完整观察池统计。接口中的当日采样时点数按当前规则版本统计。错过锚点或计算跨过该分钟不补采，真实采样时间与开始计算时间分别保存。

样本保存规则、成分版本、报价覆盖、市场环境、分钟基准及判断原因。成分文件和样本以不可覆盖的 gzip JSON 发布；相同日／规则／时点重启不重复，坏文件保留并报错。读取与写盘在现有首板工作线程内，研究写盘不持有页面快照锁；研究失败不改变既有买入门槛，通知失败仍尝试保存研究分母。同一批本地分钟复用计算结果，分区更新或候选／时间窗口改变后重算。

前向记录同时支持下面的独立成交回放。回放按首次可买信号当时的 S0F0、S1F0、S0F1、S1F1、未知分组；完整股票日覆盖另保留正例、负例和未知分母，不把跨板块混合条件拼成同板块双条件。不能用今日成分倒填历史，也不能只比较最终涨停的幸存股票。

### 日线观察研究

每个 T 日仅使用 T-1 及更早日线建立候选，再观察 T 日触板、收盘封板及 T 收盘至下一交易日的复权价格变化。这些收益不扣交易成本、不假设买入成交，不是交易胜率。

单次研究最多 366 个自然日。缺少下一交易日数据时保留缺失；不跳过缺口或填零。三种形态可能重叠，同股同日按形态分别计样本，同时提供股票日数量和数据覆盖说明。

比较按时间前 70% 训练、后 30% 留出验证；只用训练数据选择变体，并排除跨分割边界的收益标签。至少需要 30 个训练和 10 个验证有效样本；缺日历、覆盖不足或留出结果未改善时不推荐修改。历史名称、退市样本与行业历史归属仍受本地数据覆盖限制。

### 通用策略菜单的日线研究模板

仓库提供三份可导入策略，分别研究平台、超跌和趋势观察池，不自动安装到用户策略库：

- [首板平台 · 日线观察池研究](../backend/tests/fixtures/strategies/custom_first_board_platform_daily.py)
- [首板超跌 · 日线观察池研究](../backend/tests/fixtures/strategies/custom_first_board_oversold_daily.py)
- [首板趋势 · 日线观察池研究](../backend/tests/fixtures/strategies/custom_first_board_trend_daily.py)

模板通过受控的 `app.strategy.market_data.filter_first_board_daily_history` 复用首板形态计算，采用 `python_history_legacy` 执行后端。它返回每个已完成交易日的形态匹配行，策略页按所选日期展示，通用回测使用完整历史信号。策略页在北京时间 15:00 收盘前排除当日行，不使用当日尚未完成的行情判断形态；盘中查看时应选上一已完成交易日。三份模板均关闭实时支持，不增加盘中盯盘或通知。

**信号时点是 T 日收盘，回测须选择 T+1 日开盘入场。** 这对应利用 T 日及更早历史建立的下一日观察池；信号日窗口包含 T 日，因此当日已收盘涨停的股票会被近 N 日无涨停规则排除。研究不包含 T+1 盘中最低涨幅、突破价、临板距离、换手与成交额、市场环境、板块确认、昨日首板反馈、优先分或账户预算，结果不能解释为首板工作台的盘中买入信号收益。

| 参数 | 平台研究基线 | 超跌研究基线 | 趋势研究基线 |
| --- | --- | --- | --- |
| 市场范围 | 沪深主板、创业板、科创板非 ST | 同左 | 同左 |
| 近 N 日无收盘涨停 | 35 个交易日 | 35 个交易日 | 35 个交易日 |
| 最少有效历史 | 60 个交易日 | 60 个交易日 | 60 个交易日 |
| 形态窗口 | 40 个交易日 | 60 个交易日 | 40 个交易日 |
| 形态阈值 | 窗口最高价 / 最低价 − 1 ≤ 25%，收盘距窗口高点 ≤ 10% | 收盘距窗口高点跌幅 ≥ 25% | 窗口首尾收盘涨幅在 3%–40% 内，且最新收盘高于窗口收盘均值 |

每份模板只暴露自身实际使用的形态参数和三个共同参数；比例参数使用小数。历史读取长度固定为 251 根，覆盖参数允许的最长历史要求及额外前收盘参考行；实际资格仍按所选参数判定。基础过滤默认关闭，市场与风险警示过滤由共享首板规则处理；评分为空、数量不限，不额外添加通用评分门槛。历史名称、退市样本和缺失交易日仍受本地数据覆盖约束。

使用顺序：

1. 在策略页创建自定义策略，分别载入模板代码并保存；三者保持独立策略 ID。此步骤不会修改首板工作台配置或启用原本停用的工作台形态。
2. 在「回测 → 策略」选择对应策略，明确次日开盘、交易成本、仓位和统一退出规则。模板不预设止损、最大持有天数或退出信号；未补充退出规则的结果不适合作为参数优劣比较依据。
3. 在「回测 → 验证」使用稳健优化或滚动样本外检验，扫描已声明的数值、布尔或枚举参数。未扫描参数继承该策略已保存的默认值；普通回测抽屉内尚未保存的临时改动不会传入优化。
4. 优化结果的「应用到策略」写入通用策略配置，后续策略扫描与通用回测使用新值；不会调用首板工作台的规则保存接口。需要迁回工作台时，仅将验证后的对应形态参数另行保存为工作台新版本，再检查盘中确认与成交回放。

该接入只补充共享日线规则适配和可导入模板，不新增一套回测引擎，也不改变工作台已有研究、前向采样或交易链验证口径。

### 当天涨停买入、次日必卖的理想价格研究

另提供离线诊断入口 `python -m scripts.research_first_board_ideal --output <新报告.json>`（在 `backend` 目录运行）。它读取上述三个已安装策略的已保存形态参数，也可用 `--params` 指定 `platform`、`oversold`、`trend` 三组临时参数；不写回策略或工作台。默认取最近 60 个有次日行情的交易日，`--start`、`--end` 可明确限定信号区间。近一年按实际起止日期运行，不固定替换为 250 个交易日，例如 `--start 2025-11-07 --end 2026-11-05`，退出行情还须覆盖下一交易日。三种形态使用相同日期、成本、止损和数据排除口径，分别统计；跨形态重叠股票日不能直接相加为独立总样本。结果与数据排除原因保存在独立报告，不写入通用回测成交记录。

| 项目 | 固定口径 |
| --- | --- |
| 当天资格 | 仅由前一交易日及更早日线决定观察池；当天最高价须实际触及有效涨停价 |
| 买入 | 假设当天以精确涨停价成交，含一字板；不证明队列、容量或盘口成交 |
| 持有期限 | 严格于下一市场交易日退出，买入当天不止损；次日缺行情或停牌列为无法评价，不顺延 |
| 止损 | 5%；次日开盘已到止损线则按开盘价，否则最低价到线则按止损价 |
| 其他退出 | 次日未触及止损则取事后最高价；日线无法确定高点和止损先后，采用止损优先约定并统计歧义样本 |
| 成本 | 双边佣金各 0.03%，卖出印花税 0.05%；理想模型无滑点，无股数信息故不估计最低佣金 |
| 统计 | 股票日独立样本的净收益均值、中位数、胜率及最高价上界；不把样本收益累乘成账户曲线 |

**这是含事后价格的理想模型，不是可执行回测。** 通用回测菜单仍保持原有撮合与未来数据约束，不增加“次日最高价卖出”选项；其优化结果不能解释为本模型的参数优化。这里不复现工作台盘中市场、板块、成交额、换手率及优先分门控。

诊断只读原始日线和现有交易日历。为避免混用复权尺度，含公司事件的形态参考窗口直至卖出日先排除；已识别异常因子从异常日起持续隔离，不删除异常因子后重新当作有效数据。报告注明因子审核覆盖日期。使用当前股票名称和上市资料的范围研究，尚未重建历史 ST、退市样本和历史成分范围，因此不直接据此推荐或应用参数。输入文件运行中变化时停止输出；原行情、复权文件与工作台配置均不改写。

### 交易链验证

「效果验证 → 交易链验证」提供两条独立链路，报告都保留信号、委托、成交、退出、费用、原因和证据指纹。原有日线观察收益仍不作为成交收益。每次最多 92 个自然日，冻结所选规则版本；缺失或损坏证据不会补零、回填或修复原文件。

**已记录信号成交回放（模型估计）**读取不可变五分钟样本中的 `can_buy=true`，同股同日合并形态并只选择最早信号，使用实际 `observed_at` 和样本中的退出配置。不能恢复采样间漏掉的信号；`can_buy` 还包含当时账户预算门控，因此这个信号集合并非不受资金限制的全部形态机会。

模型使用信号之后完整分钟的收盘原价，加不利滑点；最早可用标签为委托所在分钟之后两分钟，成交可用时刻另取标签加一分钟。例如 10:00:17 信号最早使用 10:02 标签，在模型中记为 10:03 成交。分别返回 `entry_bar_at/entry_at`、`exit_signal_bar_at/exit_signal_at`、`exit_bar_at/exit_at`，不把分钟标签解释成精确交易所成交时刻。午休及 14:57 后不模拟成交。

| 回放参数 | 默认值 |
| --- | --- |
| 每笔独立预算 | 10000 元，包含买入费用 |
| 双边佣金 | 0.03%，沿用最低 5 元佣金规则 |
| 卖出印花税 | 0.05% |
| 单边不利滑点 | 5 基点（0.05%） |
| 分钟成交量参与率 | 1%，最多可设置为 10% |
| 入场有效窗口 | 5 分钟 |
| 退出观察上限 | 入场后 5 个交易日 |

使用原价分钟、实际交易日历、涨跌停判定价和买入数量约束。涨停买不到、跌停卖不出、容量不足均保留相应状态；缺分钟、缺尾根、缺原价证据或无法解释公司行动时标为不可验证。次日达到所选版本的定时或止损条件后，再等待后续完整分钟执行，遵守 T+1。退出观察可延伸至信号区间结束之后，但不超过运行时前一日和参数限定的交易日数。回放费率是固定研究参数，不自动还原历史税率。

历史涨跌停价通过仓库专用批量入口读取基础日线并复用既有限价计算，不依赖启动后的实时指标缓存。需要连续的前一交易日原价、上市日期和日期匹配的名称／风险警示状态；后者来自不可变样本或有 `as_of` 的同日维表。未知或冲突时不把当前 ST 状态倒填历史。退出窗口只额外读取名称证据，不增加入场信号和覆盖分母；所有使用的证据均纳入指纹。入场窗口可设为 3–30 分钟。

仅闭合且证据有效的交易进入净收益率和盈利占比；未成交、持有中、不可验证分别展示。四组及未知组使用同一执行模型，分组按首次可买时冻结。每笔交易独立等额，未模拟资金竞争、组合仓位或封板队列，因此不输出组合收益、年化或最大回撤，也不作为盈利证明。

**模拟盘成交归因**只读所选版本关联的账户，也可通过 API 显式指定账户。按 `event.id → order.source=first_board:<id> → fill.order_id` 连接实际记录；先验证整个账户账本，再按全账户 FIFO 配对并归属首板入场批次。较早手工买入不会误算为首板成本，手工卖出消耗首板批次时显示人工退出。费用使用实际记录，成交价中的滑点不重复扣除；缺历史费用时不纳入已验证净收益。

信号日期和归因截止日期均受所选结束日期限制，结束之后的卖出不提前计入闭环。部分退出只显示已实现部分，不计入完整信号的盈利占比；待卖委托不视为已卖出。公司行动数量及舍入沿用现有模拟盘 FIFO 规则，不补造账本未记录的现金分红。未发现委托不能区分未尝试下单与创建前被拒绝；缺失历史状态时间时保留证据不足。

验证不会创建账户、迁移旧账本、提交委托或读取远程行情。明细最多展示 500 条，汇总始终覆盖全部已选信号；单次回放最多 5000 个股票日信号，入场采样和额外退出名称读取各限 100 万股票时点；账本读取最多 2 万订单、10 万流水及 64 MiB。超限需缩小范围或整理数据，不静默截断统计。较大账本即使缩短信号范围仍需完整校验，不会跳过早期 FIFO 成本。
