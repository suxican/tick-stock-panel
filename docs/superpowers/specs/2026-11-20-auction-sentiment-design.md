# 情绪周期新维度：竞价情绪（设计）

> 日期：2026-11-20
> 依据：规划第 4.1 节，阶段判定升级为「宽度 + 封板质量 + 竞价情绪」。封板质量已在上一轮完成（`2026-11-19-seal-quality-design.md`），竞价情绪留到了本轮。
> 范围：与封板质量相同，**只展示，不改阶段规则**；另交付一份离线对比报告。

## 1. 意图

现有情绪周期只看收盘。集合竞价（09:15–09:25）反映的是开盘前的资金态度：昨日涨停股今天有没有溢价、全市场高开多还是低开多、有多少股竞价就封住涨停。把这些做成每日指标，展示在【市场环境】页的封板质量卡片旁边，再用离线报告说明它与现有阶段的关系。

**非目标**
- 不改 `market_phase` 的阈值和判定规则，也不改 `regime_history` 表。
- 不用 `auc_kp`（涨停委买、跌停委卖）：实测字段含义不清（不在涨停价的股也有「涨停委买」值），并且 2026 年起才有。等含义确认后再评估。
- 不在盘中实时滚动刷新；首板已有自己的竞价缓存，不重复建设。

## 2. 实测依据（2026-11-20）

- 猫爪 `daily_auc`：实时服务，按 `tradedate` 可查历史，**2019-01 起**有数据；全市场一天一次请求，耗时 1–3 秒，返回 3684（2019）到 5580（2026）行。
- 字段：`m_price`（竞价成交价）、`auc_pct_chg`（百分数）、`auc_amt`（元）、`auc_vol`（手）、`um_vol`（未匹配量，手）、`auc_turnover_rate` 等。
- 单位核对：成交量 × 价格 × 100 与成交额一致，2019 年与 2026 年各抽一只验证。
- ~~竞价涨停时用 `um_vol` 推算竞价封单额~~：**实现时实测否定**。竞价涨停的盛剑科技 `um_vol` 仅 23 手，而涨停池封单额为 4340 万元（约 1.5 万手），`um_vol` 不是买方涨停排队量。因此不做封单推算；原始字段照常落盘，标注「口径未证实」。

## 3. 数据

- 新增可路由能力 `auction`（「集合竞价」），默认猫爪，做法沿用 `price_limits`、`suspensions`：
  - 能力注册；
  - 源中立 schema `AUCTION_SCHEMA`：`date, symbol, price, change_pct（小数制）, amount（元）, volume（股）, unmatched_volume（股）, source`；
  - 按日落盘到 `market_reference/v1/auction/`，表存在即该日完整，写入后不改写；
  - 支持回填。
- 同步时间：09:27（竞价定版之后）与 15:45、20:45（补同步）。
- 回填：2019-01-02 起约 1700 个交易日，一天一次请求，按现有回填机制在后台执行；连续失败 5 次即停。

## 4. 每日指标（剔除 ST 与新股上市初期，口径与封板质量一致）

| 字段 | 定义 | 起始 |
|---|---|---|
| `high_open_ratio` / `low_open_ratio` | 竞价涨幅 >0 / <0 的家数占有竞价成交家数的比例 | 2019 |
| `median_pct` | 竞价涨幅中位数（小数制） | 2019 |
| `limit_up_open` / `limit_down_open` | 竞价价等于当日交易所涨停价 / 跌停价的家数 | 2020（交易所按日涨跌停价起点） |
| `prev_sealed` | 昨日收盘封住的家数（与封板质量的 `sealed` 同口径） | 2019 |
| `prev_mean_pct` / `prev_high_open_ratio` | 昨日封住股今日竞价涨幅均值 / 高开占比（「赚钱效应」） | 2019 |
| `prev_weak_count` | 昨日封住股今日竞价涨幅 ≤ −3% 的家数（「核按钮」） | 2019 |
| `amount` / `amount_ratio_5d` | 全市场竞价成交额，以及它相对前 5 个交易日均值的倍数 | 2019 |

- 某日竞价数据未落盘时，该日不出行，不按 0 处理。
- 近一年分位：做法与封板质量相同，取此前 250 个交易日，样本少于 60 天时为 null。

## 5. 展示与报告

- 接口：`GET /api/regime/auction-sentiment`，结构与封板质量接口相同（序列 + 最新一天 + 分位）。
- 【市场环境】页新增「竞价情绪」卡片，放在封板质量旁边；时间轴上显示当日的「昨日涨停竞价均值」。只展示，不进入阶段判定。
- 离线报告：在 `docs/` 下新增一份竞价情绪与现有阶段的对比报告，包括各阶段下指标的分布、与次日阶段变化的关系，以及与封板质量的相关性，做法同封板质量那份。

## 6. 风险

- 2019 年以前没有竞价数据；2020 年以前没有交易所涨跌停价，相关字段为 null。
- 回填约 1700 次请求，要在非交易时段执行，并留出配额。
