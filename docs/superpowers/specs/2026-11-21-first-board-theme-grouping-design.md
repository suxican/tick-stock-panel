# 首板候选表按题材分组（设计，已确认）

> 日期 2026-11-21。状态：用户已确认方案，纯前端、不改后端和买入逻辑。

## 1. 目的

首板的本质是题材卡位。候选表是一张平铺的表，看不出“这几只是同一个题材、这个题材今天有几只、谁带头”。目标：提供“按题材分组”视图，一眼看到板块效应。

## 2. 行为

- **开关**：候选表筛选区新增选项“按题材分组”，默认关闭，开关状态保存在浏览器（`first-board-group-by-theme`）。关闭时与现在完全一致。
- **每只候选归属一个题材**（同一只股票只出现一次）。候选的可选题材 = 它的联动上下文里所有 `kind === 'concept'` 的板块，加上命中的昨日主线概念；按概念名称识别。按下面的顺序取第一个分出胜负的规则：
  1. 当前显示的候选里，共享该概念的**不同股票**更多者；
  2. 命中昨日主线者（主线名次靠前者优先）；
  3. 成分股更少者（更具体的题材；缺失视为最多）；
  4. 概念名称（`localeCompare`）。
  没有任何概念时归到它的行业（`row.sector`），再没有就归到“未归类”。归属规则不使用盘中会波动的数字，刷新时一只股票不会在组之间跳动。
- **组头**一行：题材名；候选只数；昨日主线标记（带名次）；同行均涨、上涨占比、领涨股（名称、是否在涨停）。统计取自该组第一只拥有该概念联动数据的候选；联动数据缺失或已过期时显示“—”，不编造。行业组和“未归类”组不显示这些统计。
- **组内顺序**沿用候选表当前的显示顺序（含冻结顺序）；**组的先后**按各组第一只股票在当前显示顺序里的位置，所以冻结的顺序不会被分组打乱。
- 组头可点击折叠和展开（`aria-expanded`），折叠状态只在本次访问内有效，默认全部展开。
- 候选总数“今日候选 N 条”、状态分段计数、股票预览的上一只/下一只都使用分组后的显示顺序；折叠起来的组里的股票仍计入数量和翻页。
- 筛选、星标置顶、展开依据、按钮和提示条都照常工作。

## 3. 目标、非目标、反目标

**目标**：打开开关后，同题材的候选聚在一起，组头给出板块效应的关键数字。

**非目标**
- 不改后端，不改任何判定和买入逻辑，不改默认的平铺视图。
- 不显示全市场的“今日涨停数”（快照里没有，只有昨日主线有）。
- “谁先封”暂只靠组头的领涨股；组内按触板时间排序留待以后。

**反目标**
- 同一只股票在多个组里重复出现。
- 刷新让一只股票在组间跳动，或打乱冻结的顺序。
- 联动数据缺失时用 0 或空值冒充统计。

## 4. 方案对比

| 方案 | 取舍 |
|---|---|
| **A. 单归属，优先选候选间共享的概念（选定）** | 同题材的聚在一起，每只只出现一次；归属规则对孤立的股票有一定任意性 |
| B. 同一只股票在它的所有概念里都出现 | 信息最全；重复行、数量失真、操作易混 |
| C. 只按昨日主线分组，其余不分 | 简单；看不出非主线的新题材 |

## 5. 我定的选择（请核对）

1. **默认关闭**，只在你打开时分组，避免影响现有习惯。
2. 孤立候选（没有和别人共享概念、也不是昨日主线）归到“成分股更少的概念”，这是一个确定但任意的选择；如果你觉得改归行业更好，换一行规则即可。
3. 折叠状态不保存。
4. 预览翻页包含折叠组里的股票。
