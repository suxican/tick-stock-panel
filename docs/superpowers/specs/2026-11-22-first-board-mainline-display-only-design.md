# 首板页“昨日主线”降为纯展示并加风险提示（设计，已确认）

> 日期 2026-11-22。状态：用户已确认方案。纯前端文案和样式调整，不改后端判定和字段。

## 1. 目的

2018-09 到 2026-11 的回测（125574 笔首次触板、非一字的股票，按涨停价买入、次日收盘卖出，炸板计入）显示：换了现有算法、只按涨停数、规模校正、贪心去重、3 日窗口去重、去重加持续性共 6 种主线口径，“属于昨日主线前 5”的首板次日平均表现都低于主线外。按交易日计算的日均差为 -0.14% 到 -0.23%（t 值 -2.4 到 -3.9），2026-07 起为 -0.39% 到 -0.84%，大多数年份为负。可能的原因是主线里今天才首次涨停的多为跟风后排，资金优先流向连板龙头；这是推测，没有单独验证。

首板页现在把主线当作正向信号展示和筛选（蓝色“主线”标签、“只看主线”、规则页“只提示主线内个股”），与数据相反。目标：主线只作信息展示，并在属于主线的候选上给出中性的风险提示。

## 2. 改动

1. **“主线”标签改为中性灰色**：候选行和临近涨停卡片（共用 `MainlineTag`）的标签从蓝色（页面里的正向信号色）改为灰色描边；悬停说明在原有主线名称之后追加风险提示句。
2. **依据展开区新增一行风险提示**：候选属于昨日主线时，在原有主线说明之后加一行琥珀色文字，以“风险提示：”开头：“昨日主线内的首板，历史回测次日平均表现低于主线外（2018 年起，换多种口径结论一致），仅供参考。”文案不含具体数字。
3. **移除候选表的“只看主线”筛选**；对应的状态、签名项、空状态提示一并删除。
4. **题材分组组头的“昨日主线第 N”徽章改为中性灰色**；分组归属规则不变（主线仍是平局时的第二优先，用来命名题材，不是加分）。
5. **规则页**的“只提示主线内个股”开关保留，说明文字之后追加同一句风险提示；后端 `require_mainline` 字段和行为不变（默认关闭），不删字段以免旧配置读不出来。
6. **顶部“昨日主线：…”一行**保持展示，悬停说明末尾补上同一句风险提示。

## 3. 目标、非目标、反目标

**目标**：主线不再被界面当作加分或筛选依据，同时让你在看到“主线”时知道历史上它对首板偏不利。

**非目标**
- 不改后端的主线计算、`mainline` 字段、`require_mainline` 行为、任何买入判断。
- 不新增筛选或排序；不在界面里写具体回测数字。
- 不改主线对二板接力是否有用的判断（没有测过）。

**反目标**
- 把风险提示写成“不要买”，或影响 `can_buy`、阻断原因、建议金额。
- 把“主线”标签留成蓝色，继续暗示是正向信号。
- 删除后端字段导致已保存的配置无法读取。

## 4. 方案对比

| 方案 | 取舍 |
|---|---|
| **A. 降为展示，标签中性化，加风险提示（选定）** | 不再误导；改动小；仍保留主线信息 |
| B. 把主线当反向信号（非主线加分） | 数据只显示相关性，缺少独立验证，不该直接当规则 |
| C. 完全移除主线 | 信息全部丢失；后端和历史数据依旧在，反而不一致 |

## 5. 我定的选择（请核对）

1. 风险提示用“仅供参考”的措辞，因为回测有局限：概念成分用今天的成分回看历史、只看次日收盘、没算手续费。
2. 风险提示文案放在一个共享常量里，各处共用，将来改口径只改一处。
3. 规则页的开关只加说明，不加警告图标，也不禁用。

## 6. 验证

- 已有用例中依赖“只看主线”的断言需要调整（改用另一个筛选），不得删除其余断言。
