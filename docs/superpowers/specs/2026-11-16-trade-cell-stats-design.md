# 交易记录按「买入前格子」统计 设计

状态：已获用户批准 · 2026-11-16

## 意图

9 格仓位预设目前只有全市场次日等权证据可参考，不知道用户自己的交易在哪一格赚钱。本设计在结清批次时冻结"买入前一交易日所在的环境格子"，并在复盘累计统计中按格子分组，用于回头调整预设。

## 决定

- **格子取前一交易日**（用户选定）：前一交易日收盘后的格子与上限决定了买入当天的操作，与复盘仓位核对口径一致。买入当天的格子收盘后才知道，不对应任何预设。
- **结清时冻结**，从 `regime_history` 计算（`MATRIX_SENTIMENT` 映射 `state` + `capital_volume`），不依赖结论存档，存档开始前买入的交易也能算出。买入日缺失、前一交易日缺失、环境分或资金档位缺失时为 None，统计记为"未知"。
- **展示**：复盘"今日执行"累计统计在"按买入时阶段"旁新增"按买入前格子"表，字段与现有分组相同（笔数、胜率、平均盈亏）。
- 现有交易记录为 0 条，无需补算；旧记录缺字段时按"未知"读取。

## 方案取舍

| 做法 | 结论 |
| --- | --- |
| 结清时从环境历史冻结（采用） | 与 `buy_phase` 同一模式；环境历史日后重算不改变已冻结记录 |
| 读取时按买入日现算 | 否决：交易记录约定冻结上下文，现算会随重算漂移 |
| 读结论存档 | 否决：存档 2026-11-16 才开始，之前的买入无法分组 |

## 非目标与反目标

- 不自动调整预设，不把个人统计与全市场证据合成分数。
- 格子缺失时不得用相邻日顶替。

## 改动

- `trade_journal_context.buy_cell(data_dir, buy_date) -> str | None`
- `trade_journal.build_entry(..., buy_cell=None)` 新增字段；`stats()` 新增 `by_cell`（按 `ENV_MATRIX_CELLS` 顺序，最后"未知"）。
- `api/lots.py` 结清时传入 `buy_cell`。
- 前端 `TradeStats.by_cell?`，`RecapExecution` 新增分组表。
- 文档 `docs/holding-analysis.md`、`docs/data-directory.md`（`trade_journal/` 字段）。

- `build_entry` 写入；`stats.by_cell` 分组与"未知"；旧记录无字段可读。
- 结清接口写入 `buy_cell`。
