# 竞价情绪 × 情绪周期阶段：离线对比

> 日期：2026-11-20。数据：本地集合竞价归档（猫爪 `daily_auc`）、日线与情绪周期历史，口径见 `docs/superpowers/specs/2026-11-20-auction-sentiment-design.md`。
> 区间：2019-01-02 至 2026-11-19，共 1896 个交易日；竞价涨停/跌停家数从 2020 年起才有。
> 一次性脚本计算，脚本不提交。本报告只列事实，**不修改阶段规则**。

## 1. 结论

1. **竞价情绪是相对独立的新信息**：
   - 它与现有的收盘封板率几乎不相关（|r| < 0.12），与炸板率也几乎不相关（|r| < 0.08）。这一点和封板质量不同：炸板率与封板率的相关高达 0.94。
   - 只有「昨涨停竞价均值」与晋级率中度相关（0.50），这符合直觉：昨天的涨停股今天竞价越强，晋级越多。
2. **各阶段的分布有规律**：「昨涨停竞价均值」的阶段中位数从低到高依次为：
   - 退潮 1.52%；
   - 修复 2.19%、冰点 2.22%；
   - 启动 2.63%；
   - 主升 3.10%；
   - 高潮 3.67%。

   排序与阶段的情绪强弱一致，竞价涨停家数也呈同样的排序。但各阶段的四分位区间仍有较大重叠。
3. **能区分当日开盘之后的走势**：
   - 「当日全市场等权涨幅」是收盘相对昨收，本身包含竞价跳空，和竞价指标相关是机械性的，不能当作证据。
   - 因此改看「开盘→收盘」，即竞价之后的走势。按「昨涨停竞价均值」三分位分组，高组比低组多 +0.27%（t = 3.4），竞价涨幅中位数分组差 +0.34%（t = 3.6）。
   - 分 2019–2022、2023–2026 两段，方向和幅度都一致。
   - 这些信息在 09:25 就能拿到。
4. **对次日没有稳定的区分力**：六项指标中，只有「竞价涨停家数」的 t 值为 2.3，其余 |t| < 1.5。考虑到多重比较，这一项不足以下结论。
5. **建议**：
   - 本轮不改阶段规则，竞价情绪先作展示。
   - 它最有价值的用法是**当日盘中背景**（开盘后的市场强弱），而不是阶段判定或隔夜预测。
   - 如果以后要用于做T、首板的当日方向背景，需要先做样本外检验，并在个股层面验证，不能只看全市场等权。

## 6. 数据与局限

- 上游缺少 15 个交易日的竞价数据（重试后仍为空），这些天不出行：2019-05-08、2019-09-02、2019-09-04、2020-09-22、2020-09-28、2021-02-24、2021-07-22、2021-07-26、2021-08-03、2021-08-09、2021-09-06、2021-09-07、2021-09-08、2021-12-31、2022-02-08。
- 开盘→收盘用日线 enriched 的开盘、收盘价（复权口径，同日内比值不受影响），全市场等权，未剔除 ST，不代表可成交收益，也没有考虑交易成本和自相关。
- 三分位分组和 t 值只是粗筛，没有做多重比较校正。「当日开盘后」的结论在两个分段中一致，可信度相对较高；次日的结论是「没有证据」，而不是「证明无效」。
- `auc_kp`（涨停委买、跌停委卖）的字段含义未确认，`um_vol` 已被实测否定，不能推算竞价封单额，所以本报告不含竞价封单强度。
