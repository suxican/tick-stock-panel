# 封板质量 × 情绪周期阶段：离线对比

> 日期：2026-11-19。数据：本地涨停池归档与日线，口径见 `docs/superpowers/specs/2026-11-19-seal-quality-design.md`。
> 区间：2020-01-02 至 2026-11-18，共 1666 个交易日。选这个区间是为了让开板率可用，同时要求现有阶段标签非空。
> 一次性脚本计算，脚本不提交。本报告只列事实，**不修改阶段规则**。

## 1. 结论
1. **炸板率与现有的收盘封板率几乎是同一个信号**：与 `1 − seal_rate` 的相关系数为 0.94。它的主要价值在于口径更准（尾盘回封计为封住，剔除了历史 ST 和上市初期新股），而不是提供新信息。
2. **各阶段的封板质量分布大幅重叠**：除高潮期之外，各阶段的中位数都在 ±2 个百分点以内。只有高潮期四项指标同时偏高（炸板率 30.6%、早盘封板占比 54.8%、开板率 56.2%），但样本只有 17 天。
3. **对次日全市场等权涨幅没有显著的区分力**：三项指标按三分位分组，高低两组的次日均值差都远小于次日涨幅的日波动，|t| < 1。
   - 炸板率高分位组次日略差，方向在 2020–2022、2023–2026 两段一致，但不显著；
   - 早盘封板占比、开板率不单调。
4. **建议**：本轮不改阶段规则，新维度只作展示。如果以后要把「炸板率高分位」用作风险提示，需要先做样本外检验，并与现有 `seal_rate` 的增量效果比较。

- **阶段内分组**：在同一阶段内按炸板率分三组，次日均值依次为低 0.089%、中 0.098%、高 0.015%，方向与全样本一致。
- **分段稳定性**：
  - 2020–2022：低 0.017%、中 0.110%、高 0.017%；

## 5. 局限
- 次日等权涨幅是全市场统计，不代表可成交收益；没有考虑交易成本与连续日之间的自相关。
- 三分位分组和 t 值只是粗筛，没有做多重比较校正；结论是「没有证据」，而不是「证明无效」。
- 2018-09 至 2019 年的开板次数为字段缺失，本报告不含该区间。
